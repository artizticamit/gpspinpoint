Thank you for contributing to PinPoint!

How to contribute

- Open an issue to discuss large changes before implementing.
- Fork the repo and create a branch named feature/short-description or fix/short-description.
- Keep changes focused and small. One logical change per PR.
- Run flutter analyze and flutter test before submitting.
- Include tests for new features when practical.

Code style

- Follow Dart/Flutter idioms. Use dartfmt (flutter format).
- Use Riverpod for state management and GoRouter for navigation.

Pull requests

- Link the issue number and provide a clear description.
- Use the PR template provided.

Security

- Do not commit secrets or API keys. Use --dart-define for keys.
